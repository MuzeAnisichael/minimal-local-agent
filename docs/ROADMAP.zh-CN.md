# 路线图

Minimal Local Agent 保持为本地优先、单 Agent、限定工作区的轻量内核。CLI 与回环地址
Web 是两种入口；默认不需要规划器、后台任务或大型插件平台。

## v0.9 Alpha——基础已完成

- 每次模型请求前检查序列化消息字节数。默认超限就拒绝，完整历史保留在本地；
  为可信 Python 宿主预留显式的上下文缩减接口，方便未来接入可审计的压缩策略。
- 隔离评测可确定性检查文件的精确内容及不应出现的文件。这是评测断言，
  不意味着普通写入任务失败后可以自动撤销全部副作用。
- 用任务族汇总成功率、每成功任务耗时和 token，并记录固定调用上限。
  用量未知就显示未知，不推算服务商价格。

## v1.0 稳定版——已完成

1. 发布 [v1 兼容约定](COMPATIBILITY.md)：宿主扩展 API、严格的本地配置、评测输入/报告
   格式，以及受支持旧 SQLite 的原子升级；遇到更高版本的数据库会拒绝且不修改它。
2. 添加 Linux/Windows 的源码包与 wheel 全新安装检查，覆盖 CLI、嵌入、审计/历史、
   凭证及 Web。CI 检查最低/当前兼容依赖和可选 MCP 的实际集成。
3. 完成本地 Ollama 与兼容 API 的小型真实回归，隔离检查答案、工具与文件，公开经审阅的
   评测摘要；明确单任务运行边界，并拒绝重叠的 Web 任务。

最初的极简成品继续作为基础。定制优先使用模型工厂、可审计只读工具、显式 MCP 白名单
和上下文缩减接口。

## v1.1 模块化扩展——本地尚未发布

- 可选的作用域 SQLite 长期/实体记忆：候选、人工批准、版本冲突检查与有界检索；
  不引入向量服务或图引擎。
- 一次共享运行预算内的建议型规划，不是自动工作流、调度器或任务完成凭证。
- 显式只读 `Peer` 接口和基于官方 SDK 的 A2A 1.0 HTTP+JSON 适配；独立本地工作区/数据库、
  仅回环地址、超时只停止等待，不支持取消或跨进程重启恢复。
- 只读实时观察面板，分开展示原始消息、模型提交前视图、字节预算、持久化记忆和任务状态；
  断线保留最后内容，明确标示观察窗口缺口。

默认仍是单 Agent，可选模块默认关闭。配置和接口见[模块指南](MODULES.md)。
v1.1.0 尚未发布，v1.0 验证记录不代替新路径的验收结果。

## 本地验收已完成；公开发布另行进行

默认关闭、审核/版本冲突、共享预算、协议边界、面板实时/过期/缺口以及历史隔离已经
有本地回归证据。Windows 全新安装、Linux 最低/当前依赖源码测试也已通过，CLI 和文档
已核对，见[v1.1 验证记录](VALIDATION.md)。真实模型上的新模块效果和 macOS 尚未验证。
打标签、GitHub Release 和触发公开 CI 是独立发布动作，本地验收不代表已经公开发布。

## v1.x 维护

接口保持显式、实现可以替换。优先修复兼容性和实际可靠性问题、补小型回归与文档，
不为可选模块再增加一套重型编排层。

自动上下文压缩仍是可选宿主扩展，不作为默认功能。压缩、任务取消或更广的恢复机制
仅在出现可测量故障时加入，并配套测试。规划器层级、隐藏团队、向量/图服务、
Shell/浏览器工具和通用检查点编排不进入默认内核。
