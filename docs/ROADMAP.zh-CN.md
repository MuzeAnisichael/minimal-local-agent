# 路线图

Minimal Local Agent 保持为本地优先、单 Agent、限定工作区的轻量内核。CLI 与回环地址
Web 是两种入口；默认不需要规划器、后台任务或大型插件平台。

## v0.9 Alpha——当前版本

- 每次模型请求前检查序列化消息字节数。默认超限就拒绝，完整历史保留在本地；
  为可信 Python 宿主预留显式的上下文缩减接口，方便未来接入可审计的压缩策略。
- 隔离评测可确定性检查文件的精确内容及不应出现的文件。这是评测断言，
  不意味着普通写入任务失败后可以自动撤销全部副作用。
- 用任务族汇总成功率、每成功任务耗时和 token，并记录固定调用上限。
  用量未知就显示未知，不推算服务商价格。

## v1.0 稳定版——发行门槛

1. 明确并稳定 Python 扩展接口、本地配置和评测数据格式；验证受支持旧版 SQLite
   数据的升级路径。
2. 在受支持平台验证全新安装的源码包/ wheel，并使用真实本地 Ollama 与一种
   兼容接口做小型端到端回归。
3. 发布可复现的任务族评测结果，复查 CLI/Web、权限边界、隐私说明和迁移文档。

自动上下文压缩、任务取消或更广的恢复机制仅在出现可复现故障时加入。
规划器层级、隐藏子 Agent、Shell/浏览器工具和通用检查点编排不进入默认内核。
